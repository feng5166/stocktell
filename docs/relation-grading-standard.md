# 关系分级判定标准(直接 / 间接 / 情绪映射 / 弱)

> 负责人 2026-07-03 拍板:关系分级**不能按市值、名气、龙头地位来分**(否则像股票评级),
> 必须按「传导距离 + 业务暴露纯度 + 可验证入口」判定。写成四字段,不靠人工感觉;
> 后续自动管线判定 relation 也据此。跨链通用(AI 链 / 数据中心电力链 / 未来的链)。

## 四字段(每个映射标的都按这四项判定)

| 字段 | 含义 |
|---|---|
| `segment_fit` | 是否属于这条链的**核心环节**(不是"沾边环节") |
| `dc_exposure` | **数据中心 / 目标场景业务暴露**是否明确(不是通用工业 / 新能源 / 材料件) |
| `ai_power_relevance` | 是否和**本次事件的具体 delta**(如高功率 AI 数据中心升级)有关 |
| `evidence_level` | 是否有**公告 / 年报 / 订单 / 客户 / 收入占比**等可验证证据 |

## 判定条件

**直接映射**(四项必须同时满足):
- 核心环节明确(`segment_fit` ✓);
- 数据中心 / 目标场景暴露明确(`dc_exposure` ✓);
- 传导路径**不超过两跳**;
- 至少有一种可验证证据(`evidence_level` ✓)。

**间接映射**(命中任一即降为间接):
- 环节相关,但业务暴露不纯;
- 或传导超过两跳;
- 或证据不足;
- 或业务更多来自通用热管理 / 新能源 / 工业场景 / 服务器配套。

**情绪映射**:
- 只因主题(如"AI 用电""算力基础设施")被带动;
- 没有明确的**目标场景业务入口**(数据中心供配电 / 温控 / 液冷 / UPS / 机柜等);
- 传导链最长、离订单最远。

**弱映射**:
- 和目标场景建设、核心环节缺少明确连接的传统标的(传统电力 / 泛新能源等)。

## 硬边界(与三铁律一致)

1. 分级是**关系分级**,不是投资评级、不是受益程度。"直接"只表示传导距离近 / 暴露纯,**不表示一定受益**。
2. 置信度独立于关系层级:可以「直接映射 + 置信度中」——传导路径短但订单 / 收入仍待验证(如浸没液冷基础设施)。「高」置信只在有强证据时给。
3. 一句话解释**不写**"龙头 / 二线 / 确定受益 / 一定涨";写"传导路径 + 需验证什么"。
4. 某环节池内只有一个样本时,页面须注明"当前池内该环节仅此样本,后续按数据中心订单 / 业务披露补充",不让用户误解为"该环节只有这一只"。

## 落地(数据中心电力链 · 应用示例)

| 标的 | 关系 | 判定依据(四字段) |
|---|---|---|
| 盛弘股份 / 科士达 | 直接 | 数据中心 HVDC / UPS 供配电,核心环节 + 暴露明确 + 两跳内 + 有业务披露 |
| 英维克 / 申菱环境 | 直接 | 主营明确服务数据中心液冷 / 温控,传导路径直接 |
| 曙光数创 | 直接(置信中) | 浸没液冷基础设施,传导距离短;订单 / 收入占比待验证 |
| 金盘科技 | 直接(置信中,样本) | 干式变压器 + 数字化电力,数据中心供配电样本;池内变压器唯一样本,待补充 |
| 欧陆通 | 间接 | 服务器电源属**服务器配套**,机房供配电暴露间接、传导多一跳 |
| 高澜 / 同飞 / 飞荣达 | 间接 | 有液冷 / 热管理产品,但数据中心 AI 暴露纯度、收入占比、订单验证不足;或偏材料件 / 通用热管理 |
| 科华 / 思源 / 麦格米特 | 间接 | 业务多元(储能 / 电网 / 通用电源),数据中心为分部 / 新方向,占比待验证 |
| 东方电气 | 情绪映射 | 发电装备,承接「算力耗电」宏大叙事,无数据中心供配电业务入口 |
| 中国核电 / 中国广核 | 弱 | 核电运营,与数据中心建设缺明确连接 |

> 管线接入:`src/lib/relation.ts` 的核定关系(`relationForCode`)与 `chains.ts` 各环节 `defaultRelation` 应遵循本标准;人工核定新标的时对照四字段填写。
