# StockTell 2.0 · 运营维护手册

> 收尾文档 3/4。团队日常怎么改关系库、加股票、加链、回灌。**动手前跑三 CLI,提交前显式验构建。**

## 通用铁律
- **提交前验构建别用 `build | grep && commit`**——`next build` 先打 webpack "✓ Compiled" 再跑 ESLint,grep 会掩盖 "Failed to compile"。用 `npm run build`(看完整)或 `grep -q "Failed to compile" 判定`。
- JSX 文本用「」不用 ASCII 引号(react/no-unescaped-entities)。
- `*.generated.ts` 勿手改——改源再重生成。
- 查 Vercel 部署状态:`gh api repos/feng5166/stocktell/commits/<sha>/status`(沙箱连不上 Vercel API)。

## 回灌关系变更(标准 6 步)
1. 审阅台 `/admin/relation-review` 改档 / 改 reason / 批量标记 → **导出 diff**(带 dry-run 预览)。
2. 按 diff 改**源**:insight 关系→`insight-chains.ts`;审阅升级→改 `chain-relations-review-v2-audited.csv` 重生成 `chain-relations-audit.generated.ts`;direct/indirect 证据→`direct-evidence.ts` / `indirect-evidence.generated.ts`。
3. 跑三 CLI 全过:`npx tsx scripts/resolver-health.ts` · `relation-lint.ts` · `resolver-samples.ts`。
4. `npm run build` 显式确认无 `Failed to compile`。
5. 提交 + push(push main 自动部署 Vercel);**在 `relation-changelog.md` 追加一条**(日期/commit/改了什么/条数/diff/note)。
6. 生产验证:dynamic 个股页即时反映;`/stocks` 静态页下次部署 purge;看 `/admin/resolver-health` 面板。

## 新增一只股票
1. `src/data/stocks.ts` 加 Stock(code/name/market/sector/positioning/…)。
2. 若入某链:审阅台补关系(或改 insight-chains mappings / direct-evidence),segment **必须从 `segment-registry.ts` 选**、不许自由文本。
3. direct 必须补 references(法定披露入口,URL 不自产)+ 四段式 verificationPoints。走上面 6 步回灌。

## 新增一条链
1. `src/data/chains.ts` 定义 ChainConfig(id/name/segments/aMembers/insightSlug…)。
2. `src/data/insight-chains.ts` 若配 insight,加 slug + mappings。
3. `chain-relations.ts` 的 `CHAIN_META` 加 insight slug → chainId 映射。
4. `segment-registry.ts` 加该链标准环节 enum。
5. insight 管线 cron 若要每日产出,注册 cron + trigger-sources 路由。
6. 内容初稿须过负责人评审再上。

## daily signal → reviewQueue → static(沉淀路径,层②③落地后)
- 每日管线产出 dailyRelationSignals(当天),**不改 static**。
- 同一 code 多次命中 → 进 relationReviewQueue。
- 人工在审阅台确认业务入口 + 证据 → 回灌 staticRelations(走 6 步)。
- candidate promote 到正式关系:必须有一手证据(年报/公告/官网/客户案例/收入占比)+ 人审,不许凭历史同向率自动升。

## 关系升降级红线
- 历史同向统计**不反向改** relationType(同向率高≠升 direct、低≠降 weak)。
- direct 缺 references / verificationPoints = 准入 lint 拦(非零退出)。
- reason 含"龙头/受益/空间/景气"等概念词但无验证点 = lint 拦。
- 交易化喊单词(买入/卖出/加仓/目标价…)= lint 拦。
