# StockTell 视觉设计系统规范

> ⚠️ **正典在最后一章「七、2026-08-20 科技编辑风(现行)」。** 前面章节是历史记录,
> 两轮的历史记录,与现行口径冲突处(尤其「卡片不要 border、靠阴影分层」「brand=indigo 原色」
> 「涨跌只给数字」)一律以第六章为准,保留原文只为看清演进理由。

> 目的:统一视觉语言,后续 UI 迭代以此为依据。
> 定位:**「认识我、说真话、敢亮战绩、会提醒」的盯盘搭子** —— 视觉应传达**克制、可信、编辑感**,而不是"信息很密的焦虑工具"。

## 一、现状诊断(2026-06,首页今日简报)

**做得好(保留):** 三段式内容模型(为什么动 / 受益 / 散户怎么想)、和我相关↔其他分区、资金面折叠、情绪条概念。

**核心问题:**
1. **色彩语义冲突** —— 红色同时表示:涨(红涨绿跌)、高影响、链接、强调,一色多义,无法快速解码。
2. **琥珀泛滥** —— 早报/散户怎么想/资金面/过期 banner/自选高亮 全是琥珀填充块,无重点且显廉价(琥珀=警告暗示)。
3. **卡片冗长** —— 每卡含整段"散户怎么想",一屏看不下两条,滚动疲劳。
4. **层级偏弱** —— 分区标题是小灰字;两区卡片几乎同款;标题/正文/标签字阶扁平。
5. **CTA 噪音** —— "想更深入?让 StockTell 帮你解读这条→"每卡重复。
6. **情绪条未可视化** —— 一串拥挤小字数字,没用上"一眼看懂"的机会。

## 二、设计规范(迭代依据)

### 1. 色彩语义(铁律:一色一义)
- **涨跌**:仅**数字/价格**用 红涨绿跌(`text-rose-600` / `text-emerald-600`)。其它地方不得用红/绿表意。
- **影响等级**:不用饱和圆点 + 红标题。改为**卡内左侧内嵌圆角细色条**(上下留白、两端圆角,不与卡片边框相接 —— 避免"半截彩色边框"在圆角处割裂)+ **描边小标签**(不填色),低饱和:
  - 高 `rose`、中 `amber`、低 `gray`,但都走浅色/描边,不抢主体。
- **品牌强调色**:全站统一一个克制主色(建议 `indigo/slate` 系)用于链接、CTA、"你的"标识。
- **琥珀**:降级为**仅"自选/早报"专属**,且用极浅 tint(`amber-50/40`)+ 左标尺,不整块填充。

### 2. 字阶(Type scale)
- 卡片标题:`text-[15px]` / `font-semibold` / `text-gray-900`
- 正文:`text-sm` / 行高 `leading-relaxed`(1.7)/ `text-gray-700`
- meta/标签:`text-xs` / `text-gray-400`
- 分区标题:`text-base` / `font-semibold` / `text-gray-800`(明显大于正文)

### 3. 间距与容器
- 多留白、**少边框线**:卡片优先"无框 + 充足内距 + 极细分隔",而非每卡全包 `border`。
- 卡片内距 `p-4`,卡间距 `space-y-3`;分区间距 `space-y-8`。

### 4. 卡片规范(Briefing Card)
结构:`[左色条] 影响描边标签 · 标题` → 一行 meta(为什么动 / 受益A股)→ **散户怎么想(默认 2 行截断 + 展开)**。
- "散户怎么想"**默认 `line-clamp-2` + 「展开」**,点开看全文 → 卡片高度减半、可扫描。
- "受益A股"压成一行 chip;命中自选的 chip 高亮(琥珀)。
- CTA 不每卡重复:**整卡可点 / 或悬停出现轻图标**。

### 5. 分区层级
- 「和我相关」:整区给极浅品牌底,标题加大 + 自选数 badge,和「其他市场动态」明确拉开。
- 自选命中的卡:左色条/标识区分,不靠整圈琥珀 ring。

### 6. 情绪条(可视化)
- 涨跌家数 → **红绿堆叠条**(一眼看多空比);主数字(均涨跌)放大;主力净流入用箭头/色块。
- 从"读数字"变"看一眼就懂"。

## ★ Design System(已确认:品牌色 = indigo,token 进 `tailwind.config`)

> 实现机制:`tailwind.config.ts` 的 `theme.extend` 定义命名 token;`globals.css` 写 `--brand/--canvas` CSS 变量(为深色模式留口)。新增不破坏现有类,迁移分批做。

### ✅ 最终视觉(已确认,全员遵守 —— 以 `prototype/home.html` 为基准)
扁平 / 无边框 / 用光影与底色做层级,不用线条。
- **卡片**:`bg-surface`(白)+ `rounded-xl` + `shadow-sm`,**不要 border、不要左色条**。靠阴影与面板底色区隔。
- **模块面板**:两个区块同款容器 `rounded-2xl p-4`,**只用底色区分、不要 ring/border**:
  - 和我相关 = `bg-brand-50/40`(你的专区);其他市场动态 = `bg-gray-100/50`(大盘)。
- **徽章(全部扁平)**:浅填充 + 彩字,**无描边、无阴影**。
  - 影响:高 `bg-rose-50 text-rose-600` / 中 `bg-amber-50 text-amber-700` / 低 `bg-emerald-50 text-emerald-600`。
  - 自选 chip:`bg-amber-100 text-amber-800`(★);情绪 mood:同上扁平。
- **强调/当前态实心块**:用实心 brand(`bg-brand-600 text-white`),与浅填充的同类项拉出层次。**禁止用黑底/`bg-gray-900` 当强调底** —— 黑只属于中性主按钮(ink),拿来做高亮会脱离 indigo 调色板、过重突兀(如产业链"你在这"节点)。
- **"散户怎么想"**:`bg-gray-50/70` 浅灰填充块,**无左标尺/边框**。
- **早报 / 过期提示**:`bg-amber-50` 纯底,无边框(amber = 个人/提示语义)。
- **数据可视化**:涨跌家数/主力净流入用红绿小条(`bg-rose-400`/`bg-emerald-400`);红涨绿跌只给数据。
- **唯一保留的线**:页面 header 底部 `border-b`(结构分隔);组件内部必要的极细 divider 可保留。

### 颜色 token(一主一辅 + 两类语义)
| token | 值 | 用途 | 铁律 |
|---|---|---|---|
| `ink` | `#1a1d24` | 主文字/主按钮(墨色) | 主操作 |
| `brand`(=indigo 50–900) | indigo | 链接 / focus / 你的专区 / 导航当前项 / 选中 | **唯一品牌强调色**,取代散落的 blue/indigo |
| `canvas` | `#f7f8fa` | 页面底 | 取代硬编码 #f7f8fa |
| `surface` | `#ffffff` | 白卡 | |
| `amber-*` | — | "你的/个人"(早报、自选)| 稀疏,**不当品牌色** |
| `rose / emerald` | — | **仅数据**:涨跌、影响等级(低饱和) | 别处禁用 |

### 字阶 token(`fontSize`,只含 size+lineHeight,字重另用 `font-*`)
| token | px / line-height | 用途 |
|---|---|---|
| `meta` | 12 / 1.4 | 标签、时间、辅助(取代 `text-[11px]`) |
| `body` | 14 / 1.7 | 正文 |
| `title` | 15 / 1.45 | 卡片标题(取代 `text-[15px]`) |
| `h2` | 17 / 1.35 | 分区标题 |
| `h1` | 22 / 1.3 | 页面标题 |
| `display` | 24 / 1.2 | 命中率/大数字 |
> 保留 Tailwind 原生 `text-xs/sm`(≈meta/body);新代码优先用命名 token,旧的逐步收敛。

### 圆角 / 间距 / 表面
- 圆角:`chip`=8(`rounded-lg`)、`card`=12(`rounded-xl`)、`panel`=16(`rounded-2xl`)——三档。
- 间距节奏:卡内 `p-4`、卡间 `space-y-3`、分区间 `space-y-8`。
- 表面层级:`canvas`(页底)→ `surface`(白卡)→ `surface-muted`(浅灰块,取代散落 `bg-gray-50`)。

### `tailwind.config` 片段(实现参考)
```ts
import colors from "tailwindcss/colors";
theme: {
  extend: {
    colors: { brand: colors.indigo, ink: "#1a1d24", canvas: "#f7f8fa", surface: "#ffffff" },
    fontSize: {
      meta:  ["0.75rem",   { lineHeight: "1.4" }],
      body:  ["0.875rem",  { lineHeight: "1.7" }],
      title: ["0.9375rem", { lineHeight: "1.45" }],
      h2:    ["1.0625rem", { lineHeight: "1.35" }],
      h1:    ["1.375rem",  { lineHeight: "1.3" }],
      display:["1.5rem",   { lineHeight: "1.2" }],
    },
  },
}
```

### 迁移范围(确认原型效果后执行)
`blue-*`/`indigo-*`→`brand-*`、`#f7f8fa`→`bg-canvas`、`#1a1d24`→`text-ink`、`text-[11px]`→`text-meta`、`text-[15px]`→`text-title`;`text-xs/sm`、`rounded-*` 作约定逐步收敛,不一次性全量改(降低与维护者并行的撞车风险)。

## 三、迭代节奏
- **快赢(体感提升最大)**:降琥珀 + 收红(色彩语义)、卡片去边框 + "散户怎么想"折叠、CTA 收敛。
- **中期**:字阶/间距 token 化、情绪条可视化、分区层级强化。
- **勿动**:三段式内容模型、和我相关/其他分区、资金面/战绩既有逻辑。

## 六、2026-08-18 色温 / 字体校准(现行正典)

负责人诊断:上一版布局已经对了,剩下的问题收敛成两条 ——「色调偏冷、字体层级不够精致」,
整体像 SaaS 后台不像金融研究产品。**方向锚点:Bloomberg / Linear / Notion Research /
财经研究终端的混合感。黑灰是主角,紫是品牌,红绿是数据,橙是风险,颜色尽量少。**

### 6.1 底色与容器(冷灰 → 中性浅灰)

| 位置 | 值 | token |
|---|---|---|
| 页面背景 | `#F7F8FA` | `bg-canvas` |
| 主卡片 | `#FFFFFF` | `bg-surface` / `bg-white` |
| 次级分区底 | `#FAFAFB` | `bg-subtle` / `bg-gray-50` |
| 卡片边框 | `#E9EAF0` | `border-gray-200` |

**分层用边框,不用阴影**(这一条推翻二/★章的「不要 border、靠光影分层」)。
`shadow-sm` 全站重定义为 `0 1px 3px rgba(20,20,40,.04)` —— 几乎看不见,只用来把主卡
从页面底上"抬起 1mm"。禁止再出现 `border-gray-200/70` 这类半透明边框(叠在灰底上会脏)。

### 6.2 中性灰(全站主角):去蓝调

Tailwind 默认 `gray` 带蓝调,是"后台感"的主要来源。`tailwind.config.ts` 里**整条覆盖**
`gray`(并把 `slate` 指向同一条轴,消灭页面里同时存在两种灰):

`50 #FAFAFB · 100 #F1F2F5 · 200 #E9EAF0 · 300 #D3D6DE · 400 #9297A3 · 500 #7B8190 ·
600 #626878 · 700 #4A505E · 800 #363B47 · 900 #252833`

用法:900=核心结论/标题,700/800=正文,500=中性说明,400=meta(时间/来源/代码)。

### 6.3 品牌紫:降饱和 + 缩范围

主色 `#5856D6`(旧 `#5B5CE2` 偏亮偏"电商/AI SaaS"),深紫 `#403EAA`,浅紫底 `#F1F0FF`。
`indigo` 已并入品牌轴,不再是第二种紫。

**唯一用法(铁律):紫 = 可操作入口 / 当前选中 / 核心关系。** 具体只有五处:
链接、主 CTA、active 导航、关键标签(今日判断 / 今日主线 / 含自选 / 直接映射)、重点判断。

**普通说明文字一律灰黑。** 反例(本轮修掉的):主线卡「与昨日相比:资金意图 派发特征 →
中性 · 产业逻辑 不变 → 增强」整句刷 `text-brand-700`。正确写法 = 标签灰、旧态更灰、
**只有今日新状态**带状态色,一行最多一处彩色(见 `JudgmentBoard` 的 `ChangeLine`)。

### 6.4 状态色:柔和一档 + 统一 A 股口径

| 语义 | 值 | 类 |
|---|---|---|
| 上涨 / 资金进场 | `#D94C4C` | `text-red-600` `bg-red-50` |
| 下跌 / 资金流出 | `#2F9B72` | `text-emerald-600/700` |
| 风险提醒(洗盘/衰竭/合规) | `#D98B28` | `text-amber-600/700` |
| 中性 / 无信息量 | `#7B8190` | `text-gray-500` `bg-gray-100` |

**红涨绿跌全站一致,没有例外。** 本轮修掉的历史不一致:`INTENT_CHIP_CLS` 原本
绿=资金进场 / 红=资金撤出,与同一张卡里的资金微趋势柱(红=净流入)、市场状态条「主力」、
`ChainSentiment` 的涨跌条(rose=涨)全部相反。现口径:
`accumulation/rush` 红族、`distribution/exit` 绿族、`wash/exhaustion` 琥珀、
`divergence/neutral` 灰族(靠深浅区分谁更值得看)。

推论两条:
- **关系强度档不许借用红/橙**(红绿已被涨跌/资金占死,借来表示"强弱"会让同一屏的红有两种含义)。
  关系档改成「紫 + 三级灰」梯度:直接映射=`brand-50/700`(核心关系),间接/情绪/弱=三级灰。
- **✅ emoji 不许用作"判断兑现"** —— 那是一块饱和的绿,而绿=资金流出。改中性 `✓` + 琥珀 `⚠`。

### 6.5 字体:中文苹方 + 数字 Inter

```
font-family: var(--font-inter), "PingFang SC", "Microsoft YaHei",
             "Noto Sans CJK SC", "Hiragino Sans GB", -apple-system, …;
```

Inter 只打包**拉丁子集**(`src/app/fonts/InterVariable-latin.woff2`,48KB),中文自动回落
PingFang SC —— 这就是金融 Dashboard 里"数字干净、中文稳"的混排来源,不需要按语言切 class。

**必须走 `next/font/local`,不许用 `next/font/google`**:构建在杭州自托管机上跑,
`fonts.googleapis.com` 不可达,一旦联网取字体整个 build 就挂。

数字列(涨跌幅/净额/家数)加 `tabular-nums`(或 `.tnum`),否则一列数字看着在抖。

### 6.6 字号体系(定死)

| 位置 | px / 字重 | 行高 | token |
|---|---|---|---|
| 页面主标题(今日产业链推理) | 24 / 600 | 1.3 | `text-h1` |
| 模块标题(我的关注/市场状态) | 18 / 600 | 1.4 | `text-h2` |
| 主卡标题(数据中心电力) | 18 / 600(次卡 16) | — | — |
| 核心判断 / take | 15 / 500 | 1.7 | `text-title` |
| 正文 | 14 / 400 | 1.75 | `text-body` |
| meta(时间/来源/代码) | 12 / 400 · `#9297A3` | 1.5 | `text-meta` |
| chip | 12 / 500 | — | `text-meta font-medium` |
| 导航 | 14 / 500 | — | — |

两条纪律:
- **chip 不许再小于 12px**;正文不许用 `text-xs` 当正文(12px 是 meta 的专属尺寸)。
- **全站只用 400 / 500 / 600 三个字重,禁止 700+。** 投研产品不靠"喊";层级靠字号和留白拉开,
  到处加粗 = 没有重点。

### 6.7 label-value 两列

卡内的「资金 / 环节 / 映射 / 验证 / 趋势」必须是对齐的两列:label 固定宽度走灰(13px/`gray-400`),
value 走墨色(13.5–14px/`gray-800`)。不要写成一串同色小字。

## 七、2026-08-20 科技编辑风(现行正典)

负责人确认的视觉锚点不再是传统“投研终端”或 SaaS 后台，而是**科技编辑风**：空间网格、
低透明度边缘光晕、黑色大字、悬浮白卡与小面积彩色语义标签。它服务于产业理解，不允许退化成
宣传落地页或行情大屏。

### 7.1 空间与表面

- 首页使用 `.home-atmosphere`，用户侧其他页面使用 `.site-atmosphere`；后台 `/admin` 不使用。
- 背景是极浅灰蓝空间底，叠加 48–56px 细网格。网格只营造空间感，不承载数据。
- 光晕只出现在页面边缘：左侧薄荷青、右上珊瑚红、右下暖橙，透明度必须低。
- 卡片以白色、20px 左右圆角和扩散软阴影悬浮；避免每块都用明显灰边框。
- 页面标题区是带细网格的半透明白色编辑面板；正文页继续保持窄栏，不能全部扩成首页宽屏。

### 7.2 色彩职责

- 墨黑 `#171A21`：标题、主 CTA、核心结论。
- 珊瑚红 `#F05B68`：上涨/资金流入、重要事件提示。
- 薄荷青 `#24B88A`：验证/证据、自选相关；行情下跌仍沿用既有 A 股绿色口径。
- 柔紫 `#7468F2`：AI/产业链身份标签和极少量 active 点缀，不做大按钮，不染普通正文。
- 暖橙 `#E5A23A`：风险、提醒、待验证。
- 普通链接优先墨色 + 箭头/下划线；彩色只用于需要快速扫描的语义状态。

### 7.3 页面结构

- 首页首屏：左侧大标题和操作，右侧悬浮“今日判断”；无判断数据时自动退回紧凑单栏。
- 首页主体：主线大卡 + 两张次线浮卡，自选表与市场状态继续服务阅读路径。
- 列表/详情/说明/账户页：共享半透明导航、空间背景、标题面板与白卡语言；内容结构和业务逻辑不变。
- 移动端降低网格密度，标题面板改 20px 圆角；底部 TabBar 保持白色高可读层。
