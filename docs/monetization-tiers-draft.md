## 分层草案

| 层 | 能力 | 判断依据(用什么信号验证) |
|---|---|---|
| 免费(永久) | 今日推理 / 三链因果页 / 股票页 / 自选状态 / 复盘 / 归档 | 留存与信任的地基,不动摇 |
| 专业候选 | 自选链路深度追踪与提醒;每日邮件/推送;复盘长历史+按链细分;更多链覆盖;验证点跟踪清单 | `pro_interest`+`subscribe_intent` 计数、watchlist 7 日增量、digest 打开率、`stocks_filter_use` 链分布 |
| 企业候选(远期) | API/数据订阅;自定义池与链监控;团队共享自选+审阅台;报告导出 | 入站询问(feedback)、SEO 带来的机构访客特征 |

## 定价原则(先立规矩,后定数字)

1. 免费层永远能回答"今天发生了什么、传导到哪";付费买的是**深度、历史、提醒、覆盖面**,不是基础认知。
2. 绝不出现"付费荐股"形态(铁律③);付费能力全部是研究工具属性。
3. 收费动作三前置:法律意见 / 支付主体 / 退款与服务条款——缺一不上。
