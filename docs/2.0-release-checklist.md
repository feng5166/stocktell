# StockTell 2.0 · 发布验收清单

> 收尾文档 4/4。每次发版前逐条过。多数可由 CLI / 面板自动查。

## A. 关系底座(CLI:`npx tsx scripts/resolver-health.ts`,应全过)
- [ ] resolver 无 unknown relationType(六档之外)。
- [ ] 无 unknown segment(不在 `segment-registry.ts` 在册)。
- [ ] 无 empty relation(reason / verificationPoints / segment 空)。
- [ ] 无 duplicate relation(code|chainId 唯一)。
- [ ] direct 缺证据队列 = 0(缺 references/evidenceStatus/概念词无验证点)。
- [ ] indirect 缺证据队列 = 0。
- [ ] trigger 全分组(triggerGroup 非空)。
- [ ] dailyRelationSignals 未污染 static(resolver 输出全 static、无自动升降级)。

## B. 关系准入(CLI:`npx tsx scripts/relation-lint.ts`,应全过)
- [ ] direct 有 references + verificationPoints。
- [ ] indirect 至少 references 或 evidenceStatus。
- [ ] trigger 有 triggerGroup。
- [ ] reason 无交易化喊单词(买入/卖出/加仓/目标价/涨停…)。
- [ ] reason 无"龙头/受益/空间/景气"等概念词而无验证点。
- [ ] segment 在册。

## C. 关键样本(CLI:`npx tsx scripts/resolver-samples.ts`,应全过)
- [ ] 浪潮=ai-infra/direct · 中际旭创=ai-infra/光模块/direct。
- [ ] 英维克:data-center-power=direct、ai-infra=indirect(**不串链**)。
- [ ] 金山办公=ai-infra 应用侧 indirect(非供货 direct)。
- [ ] Eaton=data-center-power/trigger。
- [ ] 北方华创=已移出→null(前台显待验证、**不静默消失**)。

## D. 全站语义(Phase 3 退双轨,人工抽查)
- [ ] stock 页 peer / 上下游无"强/中/弱"主展示,全 relationType。
- [ ] Dashboard 关联图谱 / 主动发现无"强/中/弱"主展示。
- [ ] OvernightRadar 无"强/中/弱"主展示(3-D 完成后)。
- [ ] 无 `STRENGTH_BADGE` 主路径残留(3-E 完成后)。

## E. 合规口径(人工抽查:首页卡片 / stock 页 / Dashboard / OvernightRadar)
- [ ] 无交易化表达:买入/卖出/低吸/追涨/机会/受益确定/强受益/有效率/高联动/确定传导/必然兑现。
- [ ] 历史统计只叫"历史同向统计",必带"历史统计·非预测"。
- [ ] 关系标"研究框架梳理·非确认";证据前台走 EVIDENCE_LABEL(不显 verified 英文档)。
- [ ] direct 验证点标"后续应核验的公开披露项,不代表已确认受益"。

## F. 每日管线(观察期指标)
- [ ] 两链(AI 推理 / 数据中心电力)每日出草稿;AI 应用事件正确路由。
- [ ] HIGH 合规检查能阻断自动发布;飞书待审信息足够判断;人审发布后页面正确更新。
- [ ] 看门狗断产能点名具体链;失败有明确日志和降级状态。
- [ ] 链边界不污染(AI 链不混电力股 / 电力链不混泛 AI 泛能源)。
